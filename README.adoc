= PreCog Spring

Java 17+ Spring Boot application for PreCog Security.

== Prerequisites

- Java 17+
- Maven 3.8+

== Quick Start

[source,bash]
----
mvn clean install
mvn spring-boot:run
----

== API Endpoints

- `GET /api/health` - Health check
- `POST /api/scan` - Submit code for security scanning
