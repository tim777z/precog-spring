## [1.0.0] - 2026-09-26

### Added
- Spring Boot 3.5.0 baseline with Java 17
- ConfigMap-driven greeting endpoint (`GET /api/greeting`)
- Externalised configuration via `greeting.message` property (ConfigMap, env var, or packaged default)
- Strict input validation: name allow-list (letters, marks, digits, spaces, `. , ' - _`), 64 code-point limit
- Format-string injection prevention: `GreetingTemplate` parses message at start-up, rejects non-`%s` conversions
- Security headers filter: CSP (no `unsafe-inline`/`unsafe-eval`), `X-Content-Type-Options: nosniff`, `X-Frame-Options: DENY`, `Referrer-Policy: no-referrer`, `COOP/COEP: same-origin`, `Permissions-Policy` denying unused capabilities
- Structured JSON error responses via `ApiExceptionHandler` — no stack traces, exception types, or internal messages leaked
- Actuator endpoints allow-list: `health`, `info`, `metrics` only; health details `never`
- Graceful shutdown with 20s drain timeout
- JaCoCo coverage gates: 80% line coverage for `io.openshift.booster.service`, 70% total
- Checkstyle gate with defect-focused rules (unused/duplicate imports, missing braces, `==` on strings, missing `default` in `switch`, stray `System.out`)
- Maven Enforcer rules: JDK 17+, Maven 3.8+, no duplicate dependency versions, no SNAPSHOTs in release builds
- OWASP Dependency-Check profile (`mvn -Psecurity-audit verify`) with CVSS ≥7 fail threshold
- GitHub Actions CI with pinned actions, Maven caching, dependency review on PRs, weekly OWASP scan
- Dependabot configuration for weekly Maven and GitHub Actions updates
- Two-stage Docker build (build + runtime), non-root user (uid 1001), read-only rootfs, dropped capabilities, `no-new-privileges`
- Docker Compose for local development with `.env.example`
- OpenShift deployment fragment and ConfigMap manifest
- Comprehensive test suite (8 test classes): unit tests for template, service, properties, controller, exception handler, security headers; integration tests for full context and ConfigMap override
- Browser UI at `/` with no third-party scripts, CSP-compliant (external `app.js`/`app.css`, `textContent` rendering)

### Removed
- Spring Boot 1.5 / Spring Framework 4.3 (EOL 2018)
- `javax.*` → migrated to `jakarta.*`
- JUnit 4 → JUnit 5
- `com.jayway.restassured` (abandoned) → `TestRestTemplate` / `MockMvc`
- Arquillian Cube OpenShift, Arquillian JUnit, Fabric8 OpenShift Client 3.1.8 (all EOL)
- Jenkinsfile with unpinned third-party shared library
- Root-level `application.yml` and `src/test/resources/application.yml` (silent config override hazard)
- `application-local.yml` (drift hazard, duplicated packaged config)
- `src/licenses/` (generated by retired parent's license plugin, listed removed dependencies)

### Security
- No authentication on endpoints — documented as intentional for demo; production deployments must add authenticating proxy/ingress
- Forwarded headers trusted (`server.forward-headers-strategy=framework`) — documented boundary: must run behind proxy that overwrites them
- Actuator `env` and `configprops` explicitly excluded from exposure to prevent secret leakage
- Error responses never include exception details — only stable codes and safe messages
